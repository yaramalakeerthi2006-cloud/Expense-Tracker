 Expense Tracker

A simple and user-friendly **Expense Tracker Web Application** built using HTML, CSS, and JavaScript. This application helps users manage their income and expenses, track their spending, and monitor their available balance.

1.Features

- Add Transactions:** Add income and expense transactions.
- Transaction Categories:** Choose categories such as Food, Transport, Shopping, Education, Bills, Entertainment, Health, Salary, and Freelance.
- Dashboard:** View total income, total expenses, and available balance.
- Spending Overview:** Visual comparison of income and expenses using bar charts.
- Search Transactions:** Search transactions by name or category.
- Filter Transactions:** Filter transactions by income or expenses.
- Delete Transactions:** Remove unwanted transactions.
- Date Selection:** Select the transaction date.
- Local Storage:** Automatically save transaction data in the browser.
- Responsive Design:** Works on desktop and mobile devices.

2.Technologies Used

- HTML5– Structure of the application.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Functionality and dynamic updates.
- Local Storage – Store transaction data in the browser.

4.How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `expenses tracker.html` in your web browser.
4. Start adding your income and expense transactions.

5.Application Overview

The application includes:

1. Dashboard displaying total income, total expenses, and available balance.
2. Form to add new transactions.
3. Spending overview with income and expense charts.
4. Transaction history with search and filter options.

6.Data Storage

The application uses browser Local Storage to save transaction details.

- Data remains available after refreshing the page.
- Data is stored in the browser on the same device.
- Clearing browser storage may delete saved transactions.

7.Project Objective

The main objective of this project is to develop a simple expense management application that helps users understand their spending habits, manage their income, and maintain financial records efficiently.
